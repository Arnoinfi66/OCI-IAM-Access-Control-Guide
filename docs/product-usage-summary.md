# Product Usage Summary

## Product Used

Oracle Cloud Infrastructure Identity and Access Management

## Purpose
I created this repository after being accepted into the Oracle ACE Apprentice Program to document my product usage and understanding of OCI IAM access control.

## What I Created
I created a structured IAM access control guide covering:

- Users
- Groups
- Compartments
- IAM Policies
- Dynamic Groups
- Instance Principals
- Resource Principals
- Access flow documentation

## What I Practiced

I reviewed how OCI IAM controls access through group membership, policy rules, compartment scope, and workload identity patterns such as dynamic groups and instance principals.

## What I Understood

My main understanding is that OCI access control depends on multiple parts working together.
Users and groups define who is requesting access. Policies define what actions are allowed. Compartments define where the access applies. Dynamic groups and instance principals help workloads access OCI services without storing credentials directly on servers.
